# Читалка книг (PWA) — FB2 / EPUB

Лёгкая читалка для iPhone: ставится на домашний экран, работает офлайн, без сборки
и без сервера — чистый HTML/CSS/JS.

**Демо:** https://abmarat11-art.github.io/reader-pwa/

## Что умеет

- **Форматы:** FB2 (в том числе `windows-1251` и `.fb2.zip`), EPUB — оглавление, картинки, обложка.
- **Перелистывание:** свайп пальцем, страница тянется за пальцем. Режимы анимации:
  «Страница» (3D-поворот вокруг корешка с тенью и затемнением), «Сдвиг», «Плавно», «Свиток».
- **Автопрокрутка** в режиме «Свиток»: 1–40 строк в минуту, скорость регулируется.
- **Оформление:** 7 цветовых режимов (светлый, мягкий, сепия, мята, серый, ночной, чёрный),
  яркость страницы, 8 книжных шрифтов, размер, интерлиньяж, поля, выключка, переносы.
- **Библиотека:** книги и прогресс чтения в IndexedDB, обложки, оглавление, ползунок страниц.

## Как поставить на iPhone

1. Открыть демо-ссылку в Safari.
2. «Поделиться» → «На экран «Домой»».
3. Запускать с иконки — откроется во весь экран, без адресной строки, работает офлайн.

## Локальный запуск

```bash
cd reader-pwa
python3 -m http.server 8777
# открыть http://127.0.0.1:8777/
```

Service worker требует `https` или `localhost` — по IP в локальной сети офлайн-режим
не включится, остальное работает.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | разметка экранов: библиотека, читалка, настройки, оглавление |
| `app.js` | пагинация, жесты, анимации, настройки, IndexedDB |
| `parsers.js` | разбор FB2 и EPUB в единую модель книги |
| `styles.css` | темы, типографика, вёрстка страниц |
| `sw.js`, `manifest.webmanifest` | офлайн-кеш и установка на домашний экран |
| `vendor/jszip.min.js` | распаковка `.epub` и `.fb2.zip` |
